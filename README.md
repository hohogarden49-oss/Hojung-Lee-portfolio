# Hojung Lee — CMF Designer Portfolio

Personal portfolio site: color, material and finish (CMF) and automotive design work.

- `index.html` — the whole site (single page, no build step)
- `images/` — project boards, covers, portrait and résumé preview

## Run locally
Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Deploy
Works as-is on GitHub Pages, Netlify, Vercel or Cloudflare Pages (publish the repo root).
